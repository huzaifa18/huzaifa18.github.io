Brief
A halal matchmaking app people can trust, on both Google Play and the App Store.
What I did
Built matching and real-time messaging with GetX, video calls with Agora, profile photo verification and the payment gateway. Set up Firebase notifications, Crashlytics, build flavors and the release process for both stores.
Result
Launched on Google Play and the App Store.
Stack
Flutter, GetX, Firebase, Agora
Arccos Golf, a Java to Kotlin migration

analytics (TenX), Android developer, 2021 to 2022.

Brief
An existing golf-analytics Android app written in Java with an MVP architecture.
What I did
Migrated it to Kotlin, introduced Jetpack Compose and moved the architecture from MVP to MVVM. Worked on API and third-party integrations, performance and building screens from wireframes.
Result
A Kotlin, MVVM codebase with Compose in use, built with Coroutines and Retrofit.
Stack
Kotlin, Jetpack Compose, Coroutines, Retrofit, Realm
Parousia, attendance by face

Symtera Technologies, Android developer, 2020 to 2021.

Brief
Record attendance without anyone touching a device.
What I did
Built on-device face recognition with TensorFlow Lite that runs on low-end phones, plus QR code and Wi-Fi auto check-in.
Result
A working contactless attendance system. An RFID-based variant is open source as ParousiaRFID.
Stack
Kotlin, TensorFlow Lite
